## 説明

Hugo プロジェクトで生成される sitemap.xml をカスタマイズする方法を紹介します。

### カスタマイズ方法

例えば、以下のように動的にsitemap.xmlを生成する方法を紹介します。

```
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9" xmlns:xhtml="http://www.w3.org/1999/xhtml">
  {{- range .Data.Pages }}
  {{- if not .Params.ignoreSitemap }}
  {{- if not (hasPrefix .RelPermalink "/service/products/blog/") }}
  <url>
    <loc>{{ .Permalink }}</loc>
    {{- if not .Lastmod.IsZero }}K
    <lastmod>{{ .Lastmod.Format "2006-01-04" }}</lastmod>
    {{- end }}
    {{- with .Sitemap.ChangeFreq }}
    <changefreq>{{ . }}</changefreq>
    {{- end }}
    {{- if ge .Sitemap.Priority 0.0 }}
    <priority>{{ .Sitemap.Priority }}</priority>
    {{- else if eq .Kind "section" }}
    <priority>1.0</priority>
    {{- end }}
  </url>
  {{- end }}
  {{- end }}
  {{- end }}
<url>
```
#### 解説

```markdown
{{- range .Data.Pages }}

{{- end }}
```

Hugoがデータをループ処理するための構文です。`{{- range .Data.Pages }}`は、Hugoのテンプレート内でページデータをループ処理するための開始タグです。これにより、ページごとに処理が行われ、sitemap.xmlの各エントリが生成されます。

```markdown
{{- if not .Params.ignoreSitemap }}
```

front matter に`ignoreSitemap: true`が設定されているページは、sitemap.xmlに含まれないようにします。

例）front matter に ignoreSitemap: true で設定されているページ

```
---
title: ページタイトル
description: ページ概要
keywords: キーワード1, キーワード2
robots: noindex,nofollow
ignoreSitemap: true
url: /etc/index2.html
type: etc/index2
css:
js:
---
```


```markdown
{{- if not (hasPrefix .RelPermalink "/service/products/blog/") }}
```

`/service/products/blog` 以下に配置されたページは、sitemap.xmlに含まれないようにします。
